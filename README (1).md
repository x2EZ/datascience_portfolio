# NBA Salary Value Analysis

This project analyzes NBA player salary and measurable on-court production to evaluate contract value. It compares actual salary, model-predicted salary, and a direct production-per-dollar metric to identify players who appear underpaid or overpaid relative to the public statistics available.

The analysis uses Python, Pandas, data cleaning, feature engineering, exploratory analysis, regression modeling, model evaluation, and data visualization. The model is intended as decision support rather than a complete measure of player value because contract timing, injuries, role, salary-cap rules, and other factors are not fully captured in the dataset.
