# NBA Game and Trade Narrative Generator

This project explores how generative AI can create NBA game recaps, trade-impact summaries, and offseason-style narratives while reducing unsupported details. The work includes a targeted full fine-tuning iteration using Qwen and a small retrieval-augmented generation demonstration for grounding player context before generation.

The project focuses on model behavior, prompt structure, fine-tuning, holdout evaluation, retrieval, and the limitations of generative AI when information is missing.

## Notebooks

- `NBA_Game_Trade_Narrative_Fine_Tuning.ipynb`
- `Sample_RAG_Demo.ipynb`

Some training/model artifacts are intentionally not included because they are large local outputs; the notebooks document the workflow and evaluation.
