# NBA Team Success Prediction

This project evaluates whether regular-season NBA team performance metrics can reasonably predict winning percentage. It compares models with and without plus-minus so the analysis can show both how well broader team statistics explain success and how much performance improves when a direct scoring-margin measure is included.

The project uses exploratory analysis, correlation review, linear and ridge regression, random forest regression, model comparison, feature importance, and actual-versus-predicted evaluation.
