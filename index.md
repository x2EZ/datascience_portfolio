## Work / Projects

### NBA Salary Value Analysis

This project analyzes NBA player salary and measurable on-court production to evaluate contract value. It compares actual salary, model-predicted salary, and production-per-dollar metrics to identify players who appear underpaid or overpaid based on public basketball data. The project also acknowledges important limitations, including contract timing, injuries, role, market conditions, and salary-cap rules.

**Skills shown:** Python, pandas, data cleaning, feature engineering, exploratory analysis, regression modeling, model evaluation, and data visualization.

### NBA Game and Trade Narrative Generator

This project explores how generative AI can turn NBA-related prompts into readable game recaps, trade impact summaries, and offseason strategy explanations. The focus is on whether a text-generation model can produce useful basketball narratives from both structured information and short end-user-style prompts while staying grounded in the information provided by the user.

**Skills shown:** generative AI, prompt testing, model fine-tuning, retrieval-augmented generation, output evaluation, application design, and responsible handling of model limitations.

### Predicting Global Video Game Sales

This project uses historical video game sales data to test whether global sales can be reasonably estimated from non-sales attributes such as platform, genre, publisher, and release year. Regional sales fields are intentionally excluded to avoid leakage. The final model provides some predictive signal, but the project concludes that it is better used as a historical pattern-recognition tool than a precise forecasting system.

**Skills shown:** Python, pandas, scikit-learn, leakage review, regression modeling, cross-validation, sensitivity analysis, and model interpretation.

[View Project Code](https://github.com/x2EZ/datascience_portfolio/tree/main/projects/video_game_sales)

### Predicting NBA Team Success

This project evaluates whether regular-season NBA team performance metrics can reasonably predict winning percentage. The analysis compares multiple regression models and also tests model performance with and without plus-minus, since scoring margin is already very closely connected to winning. The results show that broader team statistics provide substantial predictive value on their own, while the addition of plus-minus improves performance even further.

**Skills shown:** Python, pandas, exploratory data analysis, correlation analysis, linear regression, ridge regression, random forest regression, feature importance, model comparison, and data visualization.

[View Project Code](https://github.com/x2EZ/datascience_portfolio/tree/main/projects/nba_team_success)
